# docs/

Everything that documents the code, in one place. If a claim here contradicts the running system,
the running system wins — and the file gets fixed.

| File | What it is |
|---|---|
| [DEPLOY.md](DEPLOY.md) | Run it on your own machine: requirements, the one command, each layer by hand, ports, accounts, troubleshooting |
| [SCREENS.md](SCREENS.md) | Every screen, grouped by client: desktop, phone, simulated feed |
| [ERD.md](ERD.md) | Both database schemas as ER diagrams, read out of the live database, plus what is deliberately *not* modelled |
| [diagrams/](diagrams/) | Figures generated by a script: `er-main`, `er-mock` (SVG + PNG), `architecture` |
| [screens/](screens/) | Screenshots by client: `desktop/`, `mobile/`, `mock/` |

Also available in Chinese: [简体](DEPLOY.zh-CN.md) · [繁體](DEPLOY.zh-TW.md) — the same three documents exist as
`.zh-CN.md` and `.zh-TW.md`.

## Two conventions

- **`diagrams/` is generated, `screens/` is captured.** The ER diagrams are produced by a script
  that reads `information_schema` and `pg_constraint`, so they cannot drift from the schema; the
  architecture figure is drawn by `mock-school-api/design/figures/two-systems-architecture-en.py`.
  Edit the script and rerun it, never the SVG by hand. Screenshots are captured from the running
  app and replaced rather than edited.
- **Screenshots are not reused between releases.** The set here was taken on 22 October 2026; if a
  screen changes, the screenshot is retaken, not kept for sentimental reasons.
